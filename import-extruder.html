Import Extruder

Upload dan validasi data achievement Extruder sebelum dikirim ke Dashboard Bojonegoro. Preview membantu memastikan tanggal, shift, target, dan realisasi sudah terbaca dengan benar.

Alur Import Excel → Preview → Submit Data baru akan menggantikan seluruh data Extruder yang tersimpan.
1. Upload File Excel

Format yang dibaca: sheet DATA dengan kolom Tanggal, Week, Bulan, Shift, Target Adukan, Realisasi Adukan, Target SFG Oven, Realisasi SFG Oven — sama seperti file achievement extruder yang biasa dipakai. Shift yang tidak running boleh dikosongkan (bukan diisi 0) — nilai kosong akan tetap disimpan kosong (null) supaya bisa difilter dengan benar di Dashboard Utama. Sheet Downtime juga akan dibaca otomatis untuk mengisi kartu Downtime Extruder.

2. Submit ke Dashboard
⚠️ Perhatian — data lama akan dihapus Setiap submit akan menghapus SEMUA data extruder yang tersimpan sebelumnya lalu menggantinya dengan data dari file ini. Pastikan file yang diupload sudah benar dan lengkap sebelum melanjutkan.
